# Glossary

This glossary lists every technical term introduced on this site, in alphabetical order. Each term links to the page where it is first explained, and each page lists its new terms in a Terminology callout at the top.

## 0–9 { #0-9 }

- **.hex file** – the file MakeCode creates when we download, which holds our program in a form the micro:bit can run. ([Using MakeCode](../other-robots/using-makecode.md))

## A

- **accelerometer** – a sensor that measures movement and tilt in three directions and can recognise gestures such as shaking. ([Lesson 9: Tilt Control (WuKong Manipulator)](../other-robots/wukong/lesson_09.md))
- **axis** – an imaginary line, called x, y or z, along which movement is measured. ([Lesson 5: Body Posture (XGO Robot Dog)](../other-robots/xgo/lesson_05.md))

## B

- **block** – a piece of code shaped like a jigsaw piece that we drag and snap together with other blocks to build a program. ([Using MakeCode](../other-robots/using-makecode.md))
- **brightness** – how strongly a light shines, from `0` (off) to `100` (fully on). ([Lesson 3: Lights and Eyes (PU Robot)](../other-robots/pu-robot/lesson_03.md))

## C

- **calibration** – when the robot moves its joints to a set starting position after switching on, so it knows where each joint is. ([Lesson 1: Meet the PU Robot (PU Robot)](../other-robots/pu-robot/lesson_01.md))
- **call** – to run a function by using its name, after which the program comes back to where it was. ([Lesson 6: Hand Gestures (WuKong Manipulator)](../other-robots/wukong/lesson_06.md))
- **comparison operator** – a symbol such as `==`, `!=`, `>` or `<` that compares two values and gives back `True` or `False`. ([Lesson 7: Ultrasonic Sensor (PU Robot)](../other-robots/pu-robot/lesson_07.md))
- **condition** – a check that gives back either `True` or `False`. ([Lesson 7: Ultrasonic Sensor (PU Robot)](../other-robots/pu-robot/lesson_07.md))
- **control board** – the circuit board inside the dog that drives its servo motors, following the commands the micro:bit sends it. ([Lesson 1: Meet the XGO (XGO Robot Dog)](../other-robots/xgo/lesson_01.md))

## D

- **define** – to create a function with `def`, giving it a name and a code block that Python remembers but doesn't run yet. ([Lesson 6: Hand Gestures (WuKong Manipulator)](../other-robots/wukong/lesson_06.md))
- **degree** – the unit for measuring angles, where a full turn is 360 degrees and a quarter turn is 90 degrees. ([Lesson 6: Moving Joints (PU Robot)](../other-robots/pu-robot/lesson_06.md))
- **download** – to copy our program from MakeCode onto the micro:bit so it can run there. ([Using MakeCode](../other-robots/using-makecode.md))

## E

- **elif** – short for else if, a part of an `if` statement that checks another condition when the conditions before it were `False`. ([Lesson 7: Rock, Paper, Scissors (WuKong Manipulator)](../other-robots/wukong/lesson_07.md))
- **else** – the part of an `if` statement that runs when none of the conditions are `True`. ([Lesson 7: Ultrasonic Sensor (PU Robot)](../other-robots/pu-robot/lesson_07.md))
- **event** – something that happens which the program needs to respond to, such as a loud sound. ([Lesson 8: Balance and Sound (PU Robot)](../other-robots/pu-robot/lesson_08.md))
- **event handler** – the code that responds to a particular event, such as making the robot jump when it hears a clap. ([Lesson 8: Balance and Sound (PU Robot)](../other-robots/pu-robot/lesson_08.md))
- **expansion board** – a board that the micro:bit plugs into, which adds extra connections and power for motors and sensors. ([Lesson 1: Build the Frame (WuKong Manipulator)](../other-robots/wukong/lesson_01.md))
- **extension** – an add-on that gives MakeCode extra blocks and commands for controlling a particular piece of hardware. ([Using MakeCode](../other-robots/using-makecode.md))

## F

- **factory program** – the program the robot comes with from the maker, which lets it work with the remote controller. ([Lesson 1: Meet the PU Robot (PU Robot)](../other-robots/pu-robot/lesson_01.md))
- **forever loop** – a loop that repeats the code inside it again and again for as long as the micro:bit is switched on. ([Lesson 2: First Program (PU Robot)](../other-robots/pu-robot/lesson_02.md))
- **function** – a named block of code that we can run again and again whenever we need it. ([Lesson 2: First Program (PU Robot)](../other-robots/pu-robot/lesson_02.md))

## G

- **global variable** – a variable that can be used anywhere in the program and keeps its value for as long as the program runs. ([Lesson 4: Finger Range (WuKong Manipulator)](../other-robots/wukong/lesson_04.md))
- **gripper** – the part at the end of a robot arm that opens and closes to hold things. ([Lesson 6: Robotic Arm (XGO Robot Dog)](../other-robots/xgo/lesson_06.md))

## I

- **if statement** – code that makes a decision by running its indented block only when its condition is `True`. ([Lesson 7: Ultrasonic Sensor (PU Robot)](../other-robots/pu-robot/lesson_07.md))
- **indentation** – spaces at the start of a line (four in Python) that show which code belongs to a loop or other block. ([Lesson 3: Lights and Eyes (PU Robot)](../other-robots/pu-robot/lesson_03.md))

## J

- **joystick** – a stick that we push in different directions to control something, which gives a number for how far it's pushed. ([Lesson 9: Radio Remote (PU Robot)](../other-robots/pu-robot/lesson_09.md))

## L

- **LED** – a light-emitting diode, which is a small electronic light; the micro:bit display is a 5 × 5 grid of them. ([Lesson 3: Lights and Eyes (PU Robot)](../other-robots/pu-robot/lesson_03.md))
- **light sensor** – a sensor that measures how much light is shining on it; on the micro:bit, the display LEDs do this job. ([Lesson 7: Sensor-controlled Dog (XGO Robot Dog)](../other-robots/xgo/lesson_07.md))
- **load** – to switch on a servo motor's power so it moves where it's told and holds its position. ([Lesson 6: Robotic Arm (XGO Robot Dog)](../other-robots/xgo/lesson_06.md))

## M

- **MakeCode** – a free online editor from Microsoft that lets us program the micro:bit using Blocks or Python. ([Using MakeCode](../other-robots/using-makecode.md))
- **map** – to convert a number from one range to another, such as a tilt from -1023 to 1023 into an angle from 0 to 150. ([Lesson 9: Tilt Control (WuKong Manipulator)](../other-robots/wukong/lesson_09.md))
- **micro:bit** – a small, pocket-sized educational computer with buttons, a display and sensors that we can program. ([Using MakeCode](../other-robots/using-makecode.md))
- **microphone** – an input device that detects sound and measures how loud it is. ([Lesson 8: Balance and Sound (PU Robot)](../other-robots/pu-robot/lesson_08.md))
- **milli-g** – the unit for accelerometer readings, where about 1024 milli-g equals the pull of gravity. ([Lesson 9: Tilt Control (WuKong Manipulator)](../other-robots/wukong/lesson_09.md))
- **millisecond** – one thousandth of a second, so 1000 milliseconds make 1 second. ([Lesson 2: First Program (PU Robot)](../other-robots/pu-robot/lesson_02.md))

## O

- **on start** – the block whose code runs once, as soon as the micro:bit is switched on. ([Lesson 2: First Program (PU Robot)](../other-robots/pu-robot/lesson_02.md))

## P

- **pin** – a metal connection point on the micro:bit, such as pins 0, 1 and 2, that can be used for inputs and outputs. ([Lesson 2: First Program (XGO Robot Dog)](../other-robots/xgo/lesson_02.md))
- **port** – a socket on the WuKong board that a servo motor plugs into, such as S0. ([Lesson 1: Build the Frame (WuKong Manipulator)](../other-robots/wukong/lesson_01.md))
- **pose** – the position of all the robot's joints at one moment, which can be saved and returned to later. ([Lesson 8: Teach a Pose (XGO Robot Dog)](../other-robots/xgo/lesson_08.md))
- **PRIMM** – a five-step way of learning to code: Predict, Run, Investigate, Modify and Make. ([Lesson 2: First Program (PU Robot)](../other-robots/pu-robot/lesson_02.md))
- **prototype** – an early version of a product, built so we can test an idea and improve it. ([Lesson 10: Grip Challenge (WuKong Manipulator)](../other-robots/wukong/lesson_10.md))

## R

- **radio** – a way of sending and receiving messages without wires, using invisible radio waves. ([Lesson 9: Radio Remote (PU Robot)](../other-robots/pu-robot/lesson_09.md))
- **radio group** – a number from 0 to 255 that sets which micro:bits can hear each other's radio messages. ([Lesson 9: Radio Remote (PU Robot)](../other-robots/pu-robot/lesson_09.md))
- **random number** – a number picked by chance, such as a whole number from 1 to 3. ([Lesson 7: Rock, Paper, Scissors (WuKong Manipulator)](../other-robots/wukong/lesson_07.md))
- **repeat loop** – a loop that runs its code a set number of times, written as a `for` loop in Python. ([Lesson 3: Lights and Eyes (PU Robot)](../other-robots/pu-robot/lesson_03.md))
- **RGB** – a way of describing a colour by how much red, green and blue light it contains. ([Lesson 3: Lights and Eyes (PU Robot)](../other-robots/pu-robot/lesson_03.md))
- **roll** – turning around the x-axis, like a plane dipping one wing. ([Lesson 8: Balance and Sound (PU Robot)](../other-robots/pu-robot/lesson_08.md))
- **running in the background** – carrying on by itself once started while the rest of the program keeps running. ([Lesson 6: Moving Joints (PU Robot)](../other-robots/pu-robot/lesson_06.md))

## S

- **sequence** – code running one line after the other, from the top of the program to the bottom. ([Lesson 2: First Program (PU Robot)](../other-robots/pu-robot/lesson_02.md))
- **serial communication** – sending data one piece after another along a wire, which is how the micro:bit sends commands to the XGO's control board. ([Lesson 2: First Program (XGO Robot Dog)](../other-robots/xgo/lesson_02.md))
- **servo motor** – a motor that can be controlled to turn to an exact angle or spin at a set speed. ([Lesson 1: Meet the PU Robot (PU Robot)](../other-robots/pu-robot/lesson_01.md))

## T

- **tempo** – the speed of a tune, measured in beats per minute. ([Lesson 8: Balance and Sound (PU Robot)](../other-robots/pu-robot/lesson_08.md))
- **testing table** – a table that lists each test with its expected result and actual result, so we can spot any differences. ([Lesson 10: Grip Challenge (WuKong Manipulator)](../other-robots/wukong/lesson_10.md))
- **threshold** – a set value that a reading must reach before the program counts it, such as the light level that counts as bright. ([Lesson 7: Sensor-controlled Dog (XGO Robot Dog)](../other-robots/xgo/lesson_07.md))

## U

- **ultrasonic sensor** – a sensor that measures distance by sending out ultrasound and timing how long its echo takes to come back. ([Lesson 7: Ultrasonic Sensor (PU Robot)](../other-robots/pu-robot/lesson_07.md))
- **ultrasound** – sound that is too high-pitched for people to hear. ([Lesson 7: Ultrasonic Sensor (PU Robot)](../other-robots/pu-robot/lesson_07.md))
- **unload** – to switch off a servo motor's power so it goes floppy and can be moved by hand. ([Lesson 8: Teach a Pose (XGO Robot Dog)](../other-robots/xgo/lesson_08.md))

## V

- **variable** – a named place, like a labelled box, that stores a value our program can use and change. ([Lesson 4: Finger Range (WuKong Manipulator)](../other-robots/wukong/lesson_04.md))

## W

- **WebUSB** – a way for the web browser to talk straight to the micro:bit through the USB cable, so MakeCode can send programs without us copying files. ([Using MakeCode](../other-robots/using-makecode.md))
- **while loop** – a loop that keeps repeating its code while its condition is `True`. ([Lesson 8: Smooth Movement (WuKong Manipulator)](../other-robots/wukong/lesson_08.md))

## Y

- **yaw** – turning around the z-axis, like a car turning left or right. ([Lesson 5: Body Posture (XGO Robot Dog)](../other-robots/xgo/lesson_05.md))

## Z

- **zero** – to set a servo motor to 0 degrees, its starting position, before attaching anything to it. ([Lesson 2: Zero the Servos (WuKong Manipulator)](../other-robots/wukong/lesson_02.md))
