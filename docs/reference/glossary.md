# Glossary

This glossary lists every technical term introduced on this site, in alphabetical order. Each term links to the page where it is first explained, and each page lists its new terms in a Terminology callout at the top.

## 0–9 { #0-9 }

- **.hex file** – the file MakeCode creates when we download, which holds our program in a form the micro:bit can run. ([Using MakeCode](../other-robots/using-makecode.md))

## A

- **accelerometer** – a sensor that measures movement and tilt in three directions and can recognise gestures such as shaking. ([Lesson 9: Tilt Control (WuKong Manipulator)](../other-robots/wukong/lesson_09.md))
- **and operator** – a Boolean operator that gives back `True` only if every value is `True`. ([Lesson 10: Compass and Treasure Hunt (XGO Robot Dog)](../other-robots/xgo/lesson_10.md))
- **autonomous** – able to work by itself, without a person controlling each move. ([Lesson 2: Remote Control Show (PU Robot)](../other-robots/pu-robot/lesson_02.md))
- **axis** – an imaginary line, called x, y or z, along which movement is measured. ([Lesson 5: Body Posture (XGO Robot Dog)](../other-robots/xgo/lesson_05.md))

## B

- **beat** – one of the regular pulses in a piece of music that we would tap our foot to. ([Lesson 12: Dance to the Beat (PU Robot)](../other-robots/pu-robot/lesson_12.md))
- **block** – a piece of code shaped like a jigsaw piece that we drag and snap together with other blocks to build a program. ([Using MakeCode](../other-robots/using-makecode.md))
- **brightness** – how strongly a light shines, from `0` (off) to `100` (fully on). ([Lesson 4: Lights and Eyes (PU Robot)](../other-robots/pu-robot/lesson_04.md))

## C

- **calibration** – when the robot moves its joints to a set starting position after switching on, so it knows where each joint is. ([Lesson 1: Meet the PU Robot (PU Robot)](../other-robots/pu-robot/lesson_01.md))
- **call** – to run a function by using its name, after which the program comes back to where it was. ([Lesson 6: Hand Gestures (WuKong Manipulator)](../other-robots/wukong/lesson_06.md))
- **comparison operator** – a symbol such as `==`, `!=`, `>` or `<` that compares two values and gives back `True` or `False`. ([Lesson 8: Ultrasonic Sensor (PU Robot)](../other-robots/pu-robot/lesson_08.md))
- **condition** – a check that gives back either `True` or `False`. ([Lesson 8: Ultrasonic Sensor (PU Robot)](../other-robots/pu-robot/lesson_08.md))
- **control board** – the circuit board inside the dog that drives its servo motors, following the commands the micro:bit sends it. ([Lesson 1: Meet the XGO (XGO Robot Dog)](../other-robots/xgo/lesson_01.md))
- **CSV** – short for comma-separated values, a file that stores a table of data as text with commas between the values, which a spreadsheet can open. ([Lesson 13: Sense the Feelings (XGO Robot Dog)](../other-robots/xgo/lesson_13.md))

## D

- **data logging** – recording sensor readings over time so we can study them later. ([Lesson 13: Sense the Feelings (XGO Robot Dog)](../other-robots/xgo/lesson_13.md))
- **define** – to create a function with `def`, giving it a name and a code block that Python remembers but doesn't run yet. ([Lesson 6: Hand Gestures (WuKong Manipulator)](../other-robots/wukong/lesson_06.md))
- **degree** – the unit for measuring angles, where a full turn is 360 degrees and a quarter turn is 90 degrees. ([Lesson 7: Moving Joints (PU Robot)](../other-robots/pu-robot/lesson_07.md))
- **degrees of freedom** – the number of separate ways a robot can move. Each servo motor adds one, so the PU Robot has six. ([Lesson 2: Remote Control Show (PU Robot)](../other-robots/pu-robot/lesson_02.md))
- **download** – to copy our program from MakeCode onto the micro:bit so it can run there. ([Using MakeCode](../other-robots/using-makecode.md))

## E

- **elif** – short for else if, a part of an `if` statement that checks another condition when the conditions before it were `False`. ([Lesson 10: Shy PU (PU Robot)](../other-robots/pu-robot/lesson_10.md))
- **else** – the part of an `if` statement that runs when none of the conditions are `True`. ([Lesson 8: Ultrasonic Sensor (PU Robot)](../other-robots/pu-robot/lesson_08.md))
- **evaluation** – checking that a program does what it was meant to do by comparing each requirement against our test results. ([Lesson 16: Final Project (PU Robot)](../other-robots/pu-robot/lesson_16.md))
- **event** – something that happens which the program needs to respond to, such as a loud sound. ([Lesson 11: Balance and Sound (PU Robot)](../other-robots/pu-robot/lesson_11.md))
- **event handler** – the code that responds to a particular event, such as making the robot jump when it hears a clap. ([Lesson 11: Balance and Sound (PU Robot)](../other-robots/pu-robot/lesson_11.md))
- **expansion board** – a board that the micro:bit plugs into, which adds extra connections and power for motors and sensors. ([Lesson 1: Build the Frame (WuKong Manipulator)](../other-robots/wukong/lesson_01.md))
- **extension** – an add-on that gives MakeCode extra blocks and commands for controlling a particular piece of hardware. ([Using MakeCode](../other-robots/using-makecode.md))

## F

- **factory program** – the program the robot comes with from the maker, which lets it work with the remote controller. ([Lesson 1: Meet the PU Robot (PU Robot)](../other-robots/pu-robot/lesson_01.md))
- **forever loop** – a loop that repeats the code inside it again and again for as long as the micro:bit is switched on. ([Lesson 3: First Program (PU Robot)](../other-robots/pu-robot/lesson_03.md))
- **function** – a named block of code that we can run again and again whenever we need it. ([Lesson 3: First Program (PU Robot)](../other-robots/pu-robot/lesson_03.md))

## G

- **global variable** – a variable that can be used anywhere in the program and keeps its value for as long as the program runs. ([Lesson 9: Variables (PU Robot)](../other-robots/pu-robot/lesson_09.md))
- **gripper** – the part at the end of a robot arm that opens and closes to hold things. ([Lesson 6: Robotic Arm (XGO Robot Dog)](../other-robots/xgo/lesson_06.md))

## H

- **heading** – the direction the top of the micro:bit is pointing, measured in degrees from 0 to 359. ([Lesson 10: Compass and Treasure Hunt (XGO Robot Dog)](../other-robots/xgo/lesson_10.md))

## I

- **if statement** – code that makes a decision by running its indented block only when its condition is `True`. ([Lesson 8: Ultrasonic Sensor (PU Robot)](../other-robots/pu-robot/lesson_08.md))
- **indentation** – spaces at the start of a line (four in Python) that show which code belongs to a loop or other block. ([Lesson 4: Lights and Eyes (PU Robot)](../other-robots/pu-robot/lesson_04.md))
- **IPO table** – an Input, Process, Output table that maps out what a system takes in, what it decides and what it does. ([Lesson 15: Parking Challenge (PU Robot)](../other-robots/pu-robot/lesson_15.md))

## J

- **joystick** – a stick that we push in different directions to control something, which gives a number for how far it's pushed. ([Lesson 2: Remote Control Show (PU Robot)](../other-robots/pu-robot/lesson_02.md))

## L

- **LED** – a light-emitting diode, which is a small electronic light; the micro:bit display is a 5 × 5 grid of them. ([Lesson 4: Lights and Eyes (PU Robot)](../other-robots/pu-robot/lesson_04.md))
- **light sensor** – a sensor that measures how much light is shining on it; on the micro:bit, the display LEDs do this job. ([Lesson 7: Sensor-controlled Dog (XGO Robot Dog)](../other-robots/xgo/lesson_07.md))
- **load** – to switch on a servo motor's power so it moves where it's told and holds its position. ([Lesson 6: Robotic Arm (XGO Robot Dog)](../other-robots/xgo/lesson_06.md))

## M

- **magnetic field** – the invisible area of magnetic force around a magnet or the Earth. ([Lesson 9: Magnet-controlled Dog (XGO Robot Dog)](../other-robots/xgo/lesson_09.md))
- **magnetometer** – a sensor that measures magnetic fields, used by the micro:bit as a compass. ([Lesson 9: Magnet-controlled Dog (XGO Robot Dog)](../other-robots/xgo/lesson_09.md))
- **MakeCode** – a free online editor from Microsoft that lets us program the micro:bit using Blocks or Python. ([Using MakeCode](../other-robots/using-makecode.md))
- **map** – to convert a number from one range to another, such as a tilt from -1023 to 1023 into an angle from 0 to 150. ([Lesson 9: Tilt Control (WuKong Manipulator)](../other-robots/wukong/lesson_09.md))
- **micro:bit** – a small, pocket-sized educational computer with buttons, a display and sensors that we can program. ([Using MakeCode](../other-robots/using-makecode.md))
- **microphone** – an input device that detects sound and measures how loud it is. ([Lesson 11: Balance and Sound (PU Robot)](../other-robots/pu-robot/lesson_11.md))
- **microtesla** – a unit for measuring how strong a magnetic field is; the Earth's magnetic field is about 50 microteslas. ([Lesson 9: Magnet-controlled Dog (XGO Robot Dog)](../other-robots/xgo/lesson_09.md))
- **milli-g** – the unit for accelerometer readings, where about 1024 milli-g equals the pull of gravity. ([Lesson 9: Tilt Control (WuKong Manipulator)](../other-robots/wukong/lesson_09.md))
- **millisecond** – one thousandth of a second, so 1000 milliseconds make 1 second. ([Lesson 3: First Program (PU Robot)](../other-robots/pu-robot/lesson_03.md))

## O

- **on start** – the block whose code runs once, as soon as the micro:bit is switched on. ([Lesson 3: First Program (PU Robot)](../other-robots/pu-robot/lesson_03.md))

## P

- **pin** – a metal connection point on the micro:bit, such as pins 0, 1 and 2, that can be used for inputs and outputs. ([Lesson 2: First Program (XGO Robot Dog)](../other-robots/xgo/lesson_02.md))
- **port** – a socket on the WuKong board that a servo motor plugs into, such as S0. ([Lesson 1: Build the Frame (WuKong Manipulator)](../other-robots/wukong/lesson_01.md))
- **pose** – the position of all the robot's joints at one moment, which can be saved and returned to later. ([Lesson 11: Teach a Pose (XGO Robot Dog)](../other-robots/xgo/lesson_11.md))
- **PRIMM** – a five-step way of learning to code: Predict, Run, Investigate, Modify and Make. ([Lesson 3: First Program (PU Robot)](../other-robots/pu-robot/lesson_03.md))
- **processor** – the main chip that runs programs on the micro:bit; its temperature sensor is built inside it. ([Lesson 8: Trembling Dog (XGO Robot Dog)](../other-robots/xgo/lesson_08.md))
- **prototype** – an early version of a product, built so we can test an idea and improve it. ([Lesson 10: Grip Challenge (WuKong Manipulator)](../other-robots/wukong/lesson_10.md))

## R

- **radio** – a way of sending and receiving messages without wires, using invisible radio waves. ([Lesson 14: Radio Remote (PU Robot)](../other-robots/pu-robot/lesson_14.md))
- **radio group** – a number from 0 to 255 that sets which micro:bits can hear each other's radio messages. ([Lesson 14: Radio Remote (PU Robot)](../other-robots/pu-robot/lesson_14.md))
- **random number** – a number picked by chance, such as a whole number from 1 to 3. ([Lesson 7: Rock, Paper, Scissors (WuKong Manipulator)](../other-robots/wukong/lesson_07.md))
- **repeat loop** – a loop that runs its code a set number of times, written as a `for` loop in Python. ([Lesson 4: Lights and Eyes (PU Robot)](../other-robots/pu-robot/lesson_04.md))
- **requirement** – something specific that a system needs to do, such as greeting someone who comes within 20 cm. ([Lesson 16: Final Project (PU Robot)](../other-robots/pu-robot/lesson_16.md))
- **RGB** – a way of describing a colour by how much red, green and blue light it contains. ([Lesson 4: Lights and Eyes (PU Robot)](../other-robots/pu-robot/lesson_04.md))
- **roll** – turning around the x-axis, like a plane dipping one wing. ([Lesson 11: Balance and Sound (PU Robot)](../other-robots/pu-robot/lesson_11.md))
- **running in the background** – carrying on by itself once started while the rest of the program keeps running. ([Lesson 7: Moving Joints (PU Robot)](../other-robots/pu-robot/lesson_07.md))

## S

- **sequence** – code running one line after the other, from the top of the program to the bottom. ([Lesson 3: First Program (PU Robot)](../other-robots/pu-robot/lesson_03.md))
- **serial communication** – sending data one piece after another along a wire, which is how the micro:bit sends commands to the XGO's control board. ([Lesson 2: First Program (XGO Robot Dog)](../other-robots/xgo/lesson_02.md))
- **servo motor** – a motor that can be controlled to turn to an exact angle or spin at a set speed. ([Lesson 1: Meet the PU Robot (PU Robot)](../other-robots/pu-robot/lesson_01.md))
- **state** – the situation a program is in at a particular moment, such as which mood the robot is in. ([Lesson 13: Moods (PU Robot)](../other-robots/pu-robot/lesson_13.md))
- **state machine** – a way of thinking about a program as always being in one state, with rules that decide the next state when an event happens. ([Lesson 13: Moods (PU Robot)](../other-robots/pu-robot/lesson_13.md))

## T

- **temperature sensor** – a sensor that measures how hot or cold it is, in degrees Celsius. ([Lesson 8: Trembling Dog (XGO Robot Dog)](../other-robots/xgo/lesson_08.md))
- **tempo** – the speed of a tune, measured in beats per minute. ([Lesson 11: Balance and Sound (PU Robot)](../other-robots/pu-robot/lesson_11.md))
- **testing table** – a table that lists each test with its expected result and actual result, so we can spot any differences. ([Lesson 16: Final Project (PU Robot)](../other-robots/pu-robot/lesson_16.md))
- **threshold** – a set value that a reading must reach before the program counts it, such as the distance that counts as too close. ([Lesson 10: Shy PU (PU Robot)](../other-robots/pu-robot/lesson_10.md))
- **tuning** – adjusting a value such as a distance or a speed, testing it, and adjusting it again until the program works well. ([Lesson 15: Parking Challenge (PU Robot)](../other-robots/pu-robot/lesson_15.md))

## U

- **ultrasonic sensor** – a sensor that measures distance by sending out ultrasound and timing how long its echo takes to come back. ([Lesson 8: Ultrasonic Sensor (PU Robot)](../other-robots/pu-robot/lesson_08.md))
- **ultrasound** – sound that is too high-pitched for people to hear. ([Lesson 8: Ultrasonic Sensor (PU Robot)](../other-robots/pu-robot/lesson_08.md))
- **unload** – to switch off a servo motor's power so it goes floppy and can be moved by hand. ([Lesson 11: Teach a Pose (XGO Robot Dog)](../other-robots/xgo/lesson_11.md))

## V

- **variable** – a named place, like a labelled box, that stores a value our program can use and change. ([Lesson 9: Variables (PU Robot)](../other-robots/pu-robot/lesson_09.md))

## W

- **WebUSB** – a way for the web browser to talk straight to the micro:bit through the USB cable, so MakeCode can send programs without us copying files. ([Using MakeCode](../other-robots/using-makecode.md))
- **while loop** – a loop that keeps repeating its code while its condition is `True`. ([Lesson 8: Smooth Movement (WuKong Manipulator)](../other-robots/wukong/lesson_08.md))

## Y

- **yaw** – turning around the z-axis, like a car turning left or right. ([Lesson 5: Body Posture (XGO Robot Dog)](../other-robots/xgo/lesson_05.md))

## Z

- **zero** – to set a servo motor to 0 degrees, its starting position, before attaching anything to it. ([Lesson 2: Zero the Servos (WuKong Manipulator)](../other-robots/wukong/lesson_02.md))
