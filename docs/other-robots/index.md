# Other Robots

These robots aren't part of a RoboCup Junior challenge, but we use them in class. Each one has a micro:bit inside, and we program it in **MakeCode** using either Blocks or Python.

Before starting any robot, work through [Using MakeCode](using-makecode.md). It shows how to create a project, add a robot's extension, switch between Blocks and Python, and download our program to the micro:bit. The lessons for each robot link back to it rather than repeating it.

| Robot | What it is | Lessons |
| --- | --- | --- |
| [PU Robot](pu-robot/index.md) | a walking robot with a moving head, coloured lights and an ultrasonic sensor | 15 |
| [XGO Robot Dog](xgo/index.md) | a four-legged robot dog with a robotic arm | 13 |
| [WuKong Manipulator](wukong/index.md) | a robotic hand we build from straws, thread and servo motors | 11 |

## Blocks and Python

Every example on these pages is shown twice, in a **Blocks** tab and a **Python** tab. MakeCode stores one program and can show it either way, so we can use whichever we're more comfortable with. When we choose a tab on one example, every other example on the site switches to the same tab.

The line-by-line Code explanation after each example follows the Python version, because each line of Python matches one block.
