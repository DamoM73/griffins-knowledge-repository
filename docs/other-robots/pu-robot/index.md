# PU Robot

The ELECFREAKS PU Robot is a small walking robot with a micro:bit V2 inside its head. It has six servo motors (two in each leg and two in its neck), four coloured lights, two eyes, and an ultrasonic sensor for measuring distance.

Work through the lessons in order. Each lesson adds one new part of the robot.

| Lesson | What we do |
| --- | --- |
| [Lesson 1: Meet the PU Robot](lesson_01.md) | switch the robot on and off, take out the micro:bit and set up MakeCode |
| [Lesson 2: First Program](lesson_02.md) | make the robot show a face and walk |
| [Lesson 3: Lights and Eyes](lesson_03.md) | control the coloured lights and eyes |
| [Lesson 4: Built-in Modes](lesson_04.md) | use the robot's greet, dance, jump and other modes |
| [Lesson 5: Walking](lesson_05.md) | walk a set number of steps, and keep walking until we say stop |
| [Lesson 6: Moving Joints](lesson_06.md) | move the head one servo at a time |
| [Lesson 7: Ultrasonic Sensor](lesson_07.md) | measure distance and react to a hand wave |
| [Lesson 8: Balance and Sound](lesson_08.md) | read the robot's tilt and react to a clap |
| [Lesson 9: Radio Remote](lesson_09.md) | drive the robot from a second micro:bit |

!!! warning "The micro:bit buttons are inside the head"
    Once the micro:bit is closed inside the robot's head, we can't press buttons A and B. So PU Robot programs start in **on start**, or react to the robot's sensors (a hand wave or a clap) instead of the buttons.
