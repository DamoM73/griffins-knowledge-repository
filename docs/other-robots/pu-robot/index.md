# PU Robot

The ELECFREAKS PU Robot is a small walking robot with a micro:bit V2 inside its head. It has six servo motors (two in each leg and two in its neck), four coloured lights, two eyes, and an ultrasonic sensor for measuring distance.

Work through the lessons in order. Each lesson adds one new part of the robot.

| Lesson | What we do |
| --- | --- |
| [Lesson 1: Meet the PU Robot](lesson_01.md) | learn the robot's parts, switch it on and off, take out the micro:bit and set up MakeCode |
| [Lesson 2: Remote Control Show](lesson_02.md) | drive the robot with the remote controller and put on an imitation show |
| [Lesson 3: First Program](lesson_03.md) | make the robot show a face and walk |
| [Lesson 4: Lights and Eyes](lesson_04.md) | control the coloured lights and eyes |
| [Lesson 5: Built-in Modes](lesson_05.md) | use the robot's greet, dance, jump and other modes |
| [Lesson 6: Walking](lesson_06.md) | walk a set number of steps, and keep walking until we say stop |
| [Lesson 7: Moving Joints](lesson_07.md) | move the head one servo at a time |
| [Lesson 8: Ultrasonic Sensor](lesson_08.md) | measure distance and react to a hand wave |
| [Lesson 9: Variables](lesson_09.md) | store settings in variables and count hand waves |
| [Lesson 10: Shy PU](lesson_10.md) | behave three different ways depending on how close we are |
| [Lesson 11: Balance and Sound](lesson_11.md) | read the robot's tilt and react to a clap |
| [Lesson 12: Dance to the Beat](lesson_12.md) | time the robot's moves to music |
| [Lesson 13: Moods](lesson_13.md) | switch the robot between moods with a clap |
| [Lesson 14: Radio Remote](lesson_14.md) | drive the robot from a second micro:bit |
| [Lesson 15: Parking Challenge](lesson_15.md) | stop as close to a wall as possible |
| [Lesson 16: Final Project](lesson_16.md) | design, build and test our own robot behaviour |

Lessons 1, 2, 9, 10, 12, 13, 15 and 16 are based on activities from the [ELECFREAKS PU Robot wiki](https://wiki.elecfreaks.com/en/microbit/robot/pu-robot-kit/).

!!! warning "The micro:bit buttons are inside the head"
    Once the micro:bit is closed inside the robot's head, we can't press buttons A and B. So PU Robot programs start in **on start**, or react to the robot's sensors (a hand wave or a clap) instead of the buttons.
